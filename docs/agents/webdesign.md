# SITE BUILDER — Web Design & Code Generator

## What it does
Site Builder generates production-ready HTML, CSS, and JavaScript code for websites and web components. It handles responsive layout, modern design patterns, animations, and framework-agnostic component generation. Output is ready to copy-paste into your project or save directly as a file.

---

## How to use

1. **Describe what you want** — a landing page, a hero section, a navigation bar, a pricing table, a contact form, etc.
2. *(Optional)* Specify **design preferences** — colour scheme, typography style (modern/minimal, bold, corporate, playful), dark/light mode.
3. *(Optional)* Set **technical constraints** — vanilla HTML/CSS only, Tailwind CSS, Bootstrap, specific responsive breakpoints.
4. *(Optional)* **Toggle options** in the sidebar:
   - Responsive (mobile-first)
   - Framework (vanilla / Tailwind / Bootstrap)
   - Line count target
5. **Select a Provider & Model** — a coding-focused model (Claude Sonnet, GPT-4o, DeepSeek) produces cleaner code.
6. Click **Generate**.

---

## What Site Builder generates

- **Full landing pages** — hero, features, pricing, testimonials, CTA, footer
- **Individual components** — nav, cards, modals, forms, tables, buttons
- **CSS animations** — fade-in, slide, parallax, hover effects
- **Responsive layouts** — flexbox and CSS grid with breakpoints
- **Dark mode** — CSS variables-based theme switching
- **Accessibility** — semantic HTML, ARIA labels, keyboard navigation
- **JavaScript interactions** — smooth scroll, mobile menu toggle, form validation

---

## Sidebar options

| Option | Description |
|---|---|
| Responsive | Generates mobile-first CSS with standard breakpoints (sm/md/lg/xl) |
| Framework | Vanilla CSS, Tailwind utility classes, or Bootstrap grid |
| Line count | Approximate target length — short (component), medium (section), long (full page) |
| Copy | Copy the generated code to clipboard |
| Save | Save the output as an .html file |
| Clear | Reset the output area |

---

## Tips
- For **colour schemes**, give hex codes or describe the brand (e.g. "dark navy and electric blue, premium tech feel").
- For **full pages**, start with a clear sitemap description — e.g. "landing page with: hero, 3-feature section, pricing table with 3 tiers, contact form, footer".
- Generated code is meant as a **starting point** — edit typography, spacing, and content to match your brand.
- Use **Tailwind** output if your project already uses Tailwind for consistency; use **vanilla** for zero-dependency pages.
