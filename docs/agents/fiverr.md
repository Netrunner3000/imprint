# ATELIER — Fiverr Logo Gig Studio

## What it does
Atelier is an end-to-end Fiverr logo gig assistant. It has three modes: generating DALL·E image prompts for logo concepts, writing Fiverr gig descriptions that convert, and drafting professional client delivery messages. Together these three modes cover the full lifecycle of a logo design gig on Fiverr.

---

## Modes

### 1. Logo Prompt Generator
Generates a set of detailed DALL·E / Midjourney prompts for logo concepts based on a client brief.

**How to use:**
1. Enter the **client's business name** and **industry/niche**.
2. Describe the **style** — minimalist, bold, vintage, tech, playful, etc.
3. *(Optional)* Add **colours**, **symbols**, or **mood references**.
4. Click **Generate Prompts**.

**Output:** 3–5 distinct DALL·E prompts with style rationale, ready to paste into an image generator.

---

### 2. Gig Description Writer
Writes a complete, SEO-optimised Fiverr gig description — title, intro, bullet features, packages, and FAQ.

**How to use:**
1. Describe **what you offer** (logo type, file formats, turnaround, revisions).
2. *(Optional)* Specify your **target client** (e.g. startups, restaurants, coaches).
3. *(Optional)* Mention **keywords** you want included.
4. Click **Write Gig**.

**Output:** Full gig description with title, SEO-friendly intro, 3-tier package summary, and FAQ section — ready to paste into Fiverr.

---

### 3. Client Delivery Message
Drafts a professional delivery message for completed logo work.

**How to use:**
1. Enter the **client's name** and **project brief** (what you delivered).
2. *(Optional)* Note any **revision policy** or **file format details**.
3. Click **Draft Message**.

**Output:** A warm, professional delivery message that explains what's included, invites feedback, and sets expectations for revisions.

---

## Tips
- For **Logo Prompts**, be as specific as possible about the brand personality — "tech startup" is weaker than "AI cybersecurity startup with a premium, trustworthy feel".
- For **Gig Descriptions**, include your USP (unique selling point) — e.g. "24-hour delivery" or "unlimited revisions" — so Atelier can emphasise it.
- For **Delivery Messages**, mention the file formats included (SVG, PNG, PDF, AI) — clients appreciate the detail and it reduces revision requests.
